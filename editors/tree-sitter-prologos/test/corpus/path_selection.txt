; Path selection — spec: docs/research/2026-07-28_path-selection-spec.md §2.
;
; Every step opener is `token.immediate`, because §2.2 makes three characters
; juxtaposition-sensitive: `x:k` is a broadcast step but `x :k` is application
; to a keyword literal, and `x{…}` is a select block but `x {…}` is a literal.
; The pair of tests at the end pins exactly that distinction — without them a
; broadcast rule can look correct while never firing at all, which is how the
; first cut of `broadcast_step` shipped green and did nothing.

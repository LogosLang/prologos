Prologos Propagator Network — Stratified BSP Demo

Worked example: graph-reachability with negation-as-failure (S0 monotone → S1 NAF stratification).

This page shows a small Prologos propagator network executing a stratified Datalog-style derivation. The network derives path(X,Y) as the transitive closure of edge(X,Y), then derives unreachable_from_a(X) via negation-as-failure on the path relation. Negation requires stratification: the NAF rule cannot fire until the monotone path derivation has reached fixpoint (quiescence). The visualization makes the strata, cells, and propagator firings explicit.

Lattice-theoretic framing: each derived-fact cell holds a join-semilattice value (set of facts, monotonically growing under set-union). Each S0 propagator is a monotone Q-module morphism on the cell network. Quiescence is a fixed point in the Tarski-Knaster sense. The S1 NAF stratum activates as a higher-order computation — it reads the converged S0 lattice values and computes a non-monotone derived value.

How to read the demo

  • Cells (rounded boxes) hold lattice values. Set-typed cells (edge, path, vertex, unreachable_from_a) hold join-semilattice values that grow monotonically under set-union. The boolean path_quiescent is a 2-element lattice {false ≤ true}.
  • Propagators (boxes inside stratum bands) react to cell changes and write to other cells. Each propagator belongs to exactly one stratum.
  • Arrows show data flow. An arrow from cell C to propagator P means P reads C; an arrow from P to C means P writes to C.
  • Strata are the colored bands. The BSP scheduler drives S0 to quiescence first, then activates Topology stratum to detect quiescence, then activates S1 NAF.
  • Click a cell to inspect its current value in detail.

Architectural connection

This is exactly the propagator network architecture Prologos's elaborator + solver use, scaled down for visualization. Every cell and every propagator in the real system follows the same pattern: cells hold lattice values, propagators are monotone reactive functions, strata stratify non-monotone steps, BSP scheduling drives quiescence. The empirical sweep findings in the variety-categorization report were computed using property-cells + property-test-propagators on this same architecture (off-network scaffolding for now; sister-track migrates them on-network).

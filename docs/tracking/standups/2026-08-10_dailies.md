### (xx) Q_U32 RULED — the guard rail is PINNED BEFORE the design, and the discriminator is POSITION, not spelling — `f63612e7`

**Why.** DEFERRED 103 was named the first question of attempt 3 because, if a
bare `*` stays legal in pattern position, any mint must be pattern-position-aware
**at a stage that does not know it is in a pattern**. The owner ruled it out of
existence: refuse bare `*` in pattern position, provided the arithmetic uses are
untouched — "`* 3 5`, `* 3 _`, `[* _ 2]`, mixfix `.(4 * 5)`".

**⭐ Surprise, and it is the finding that makes the ruling implementable.** The
four named spellings are not the whole guard rail. Since Numerics N6e-E2
**operators are first-class values**, `reduce * 1 '[2 3 4]` → 24 and `let op *` /
`[op 3 4]` → 12 put a **BARE, unglued `*`** in argument and binding position. So
a refusal keyed on "a bare `*` token" would break live surface: **the
discriminator has to be POSITION.** Found by sweeping rather than by reasoning
from the four given examples — the enumeration-under-counts pattern (Watching 2),
caught this time on the input side.

**Also measured**: the ruling is BROADER than the defect. `match q | * -> 99`
yields 99 at 0 errors and `defn f | * -> 1` works — both harmless today, both
refused by Q_U32. Accepted as the simpler rule, and monotone per spec §3.6.
Bracket destructuring (`let [a *] pair`) reads as APPLICATION and is NOT in the
domain.

**Observation for the mini-design, explicitly not a ruling**: the arm loss is
observable at the **pattern compiler**, which knows it is in a pattern. So the
refusal need not sit at the reader — the same move Q_U31 used to keep a context
test out of the grouper.

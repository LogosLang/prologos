### The one real regression + the design refinement it forced

The only non-display-churn failure was `postfix-index-03`: `def xs : (List (Map Keyword Nat)) := '[{:age 25N} …]`. Diagnosis took several passes and was worth it — it revealed that **D.2's "the Record→Map α is only a `check` arm; leave `unify`/`subtype-predicate` untouched" was insufficient**. The α must ALSO be reachable from (a) `subtype?` + `structural-subtype-ground?` (nested subsumption: `(List Record) <: (List Map)` recurses through the covariant List walk — which is `structural-subtype-ground?`, NOT `subtype?`, so the bridge had to go in BOTH), and (b) `classify-whnf-problem` in `unify` (polymorphic subsumption: `(cons {:age 25N} nil)` commits `cons`'s element param to the record, which meets the `(Map K V)` annotation through `unify`, not `check`). **D11 (no record<:record) is preserved** — this is the record→Map *bridge* (a record projected to its uniform-Map view, Q_E), reachable wherever a record meets a Map in a subsumption context. Pre-s2 it "worked" only because `(Map K Open)`'s `Open` unified with `Nat`; records don't. Documented in the design doc §11a.

### Surprises / lessons (s2)

- **Minting is the point of no return for annotation-satisfaction** — the moment `{:a 1}` types as a record, every Record-vs-Map flow (direct literal via B1, fvar via subsumption, nested via subtype?, polymorphic via unify) must be handled or it regresses. The atomic slice is bigger than "projection."
- **The α needs FOUR reach points, not one** (check-subsumption, qtt fallback, subtype?/structural-subtype-ground?, unify classify) — the "one local check arm" framing under-counted. Each is a different entry into subsumption.
- **`last-string` skips non-strings** — the T-2 tests' error cases can't be asserted via `last-string` (it returns the prior def line); use `(ormap prologos-error? result)` on the raw list.
- **The T-2 "Open by Design" contract file is now superseded** (D7) — its α-Open-trust tests (map-get-on-non-map-returns-none, etc.) now assert the sound static behavior (projecting a field off a scalar = type error). More sound; a real (intended) semantic change for dynamic-map idioms → use `(Map K V)` annotation or `nil-safe-get`.
- **Diagnosis discipline paid off**: the postfix regression took ~5 hypothesis-test cycles (subtype? bridge → structural-subtype-ground? bridge → unify direction). The var-vs-literal isolation probe (`def xs := zs` works, `'[…]` fails) was the key that localized it to polymorphic-instantiation-via-unify.

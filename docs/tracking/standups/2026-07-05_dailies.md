## Surprises / design choices worth remembering

- **The empirical reframe beat the abstract framing.** The original Q1/Q2/Q3 (representation / row-depth / scope-split) dissolved once we *ran* the code: F1 = "make the unannotated vt concrete," and the real fork is uniform-join vs per-field, not the abstract carrier menu. **Run it before theorizing about it.**
- **`Open` is formalized prior art, not debt** — it's `★`/`&{}`. That flipped D1 from "delete with scaffolding" to "relocate into the dyn tail, then delete" (D7). A nicer, more principled story.
- **One carrier, decomplected laws.** The frontier unifies the row *substrate* (Morris–McKinna monoidal rows; Ur/Web tuples-as-Nat-records; Roc same runtime rep) but *nobody unifies the surface* — Casinghino/Tjoa (ML'24) explicitly rejected reorderable tuples for order/layout reasons. So: shared carrier + key-domain tag selecting the law-set. **Active-enforcement caveat noted in the design: a law that reads the carrier without checking the key-domain tag is a latent law-crossing bug.**
- **S2 (generic-walker blindness) was demonstrable, not theoretical.** `occurs?`/`collect-meta-ids` recurse via `struct->vector` but a *list field is not a struct*, so field metas were invisible — probe confirmed, explicit Record arms fix it. Codified a candidate pipeline.md checklist add: "sub-exprs inside a non-struct container → audit every generic walker."
- **Grounding error caught by the critique**: D.1 claimed "no map `merge` exists" — it does (`lib/.../map.prologos`, right-priority, feeds `impl Lattice`). D10's *semantics* lock survived; the "no legacy" justification didn't. **Re-verify grounding claims across the whole tree, not just the obvious dir.**
- **Delegation discipline held**: grounding-audit + design-options-panel + two research workflows did the reading/enumeration in disposable context; the **design dialogue + the D.2 authoring + s1 implementation stayed main-session**. Kept main context lean across a very large arc.
- **`record-map-field-types` helper** centralized the ~7 field-recursion sites (shift/subst/zonk/nf/…) into one reconstruction point — small blast radius, uniform.

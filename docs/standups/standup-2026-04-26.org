** On distributivity and semidistributivity — what each gets us

🤖
**On distributivity and semidistributivity — what each gets us:**

**Distributivity** is the strongest of the three (distributive ⇒ SD; reverse doesn't hold). The law:

```
a ∧ (b ∨ c) = (a ∧ b) ∨ (a ∧ c)        (and dually for ∨ over ∧)
```

What it concretely buys you:

1. **Birkhoff representation (finite case)**: every finite distributive lattice is isomorphic to the lattice of order-ideals of its poset of join-irreducibles. Translation: distributive lattices are essentially "set lattices" — they have a concrete representation as subsets-of-something. For us, this means our type lattice can be reasoned about *as if it were a set algebra*, even when it doesn't look like one syntactically.

2. **DNF/CNF canonical form**: every element has a canonical disjunctive (or conjunctive) normal form. Equality is decidable via structural equality on canonical forms. We have a partial form of this already (`build-union-type`'s ACI normalization). Distributivity validates the canonical form algorithm's correctness.

3. **Heyting algebra** (with pseudo-complement): bounded distributive + relative pseudo-complement = Heyting. Pseudo-complement `a → b = max{x | x ∧ a ≤ b}` gives you precise incompatibility — useful for error reporting ("you wrote T₂ where T₁ was expected; the precise mismatch is T₂ - T₁"). Track 2H scaffolded this for the subtype lattice; if equality is also distributive, the Heyting structure becomes available for equality-merge contexts (unification-failure diagnostics).

4. **Boolean algebra** (with complement): Heyting + complement = Boolean. Unlocks SAT/CDCL with watched literals, conflict-driven learning. UCS Master flags this as the dispatch target for Boolean domains. Type lattice is unlikely to be Boolean (no negation), but having distributivity is the precondition for asking the question.

5. **Quantale composition**: distributive lattice + tensor = the multiplicative structure UCS targets for resource constraints (QTT multiplicities, session linearity, effect ordering). Distributivity is the unspoken precondition for these compositions to behave well.

6. **Galois bridges compose cleanly**: cross-domain bridges (type ↔ session, type ↔ multiplicity) are well-behaved when both sides are distributive. Mixed distributive/non-distributive bridges have subtle composition pathologies.

**Semidistributivity** is the conditional weakening:

```
SD∨: a ∨ b = a ∨ c  ⇒  a ∨ b = a ∨ (b ∧ c)
SD∧: dual
```

Strictly weaker. **Free lattices satisfy SD but NOT distributivity** (Freese-Nation Theorem 1.21). Reading-Speyer-Thomas 2019 gives constructive canonical form for finite SD lattices.

What SD buys you that distributivity doesn't strictly require:

1. **Coverage of "wider" algebraic structures**: subgroup lattices, congruence lattices, free lattices — all SD but not distributive. SD is the "tightest distributivity-like property that holds in these natural settings."
2. **Robinson-style unification**: most-general unifier exists in SD lattices via the SD law applied to unification problems. This is part of why structural unification on tree lattices works — they're SD even when not fully distributive.
3. **Convex geometries** (Adaricheva-Gorbunov-Tumanov 2003): SD lattices are the algebraic counterpart of convex geometries (matroid duals), useful for combinatorial reasoning.
4. **Free-lattice algorithmic results** (Freese-Nation Ch XI): Whitman's algorithm, breadth-4 theorem, canonical form — all available in SD settings.

**The hierarchy in one line:**
- Free lattice (most expressive, no equations beyond axioms)
- ⊃ SD (some structure)
- ⊃ Modular (a ≤ c ⇒ a ∨ (b ∧ c) = (a ∨ b) ∧ c)
- ⊃ Distributive (full law, sets-as-lattices)
- ⊃ Heyting (distributive + pseudo-complement)
- ⊃ Boolean (Heyting + complement)

Each step **gives you more algorithms** (canonical-form algorithms get cheaper, decision procedures get more efficient) but **constrains what lattices live there** (more equations, fewer models).

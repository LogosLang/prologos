Identity Elements and Algebraic Structure

This chapter covers the algebraic infrastructure that ties arithmetic traits together:

* AdditiveIdentity --- the zero element for each type * MultiplicativeIdentity --- the one element for each type * Num and Fractional bundles --- grouped constraints * Generic arithmetic --- first-class wrappers (plus, minus, times, divide, negate-fn, abs-fn) formerly in generic-operations * Sum/product/int-range --- generic folds using identity traits, formerly in generic-operations * Algebraic laws --- property declarations for testing

The identity traits are single-method traits where the method is a *value*, not a function --- the dictionary IS the zero/one element itself. This enables sum and product to work generically over any numeric type.

======================================== sum — generic additive fold over a list ======================================== sum [Add A] [AdditiveIdentity A] (List A) -> A Uses the AdditiveIdentity dict as the zero element and Add-add for accumulation. Left fold (reduce) for efficiency.

spec sum [Add A] -> [AdditiveIdentity A] -> [List A] -> A
  :doc "Sum a list using generic addition and an additive identity as zero"
defn sum [add-dict id-dict xs]
  reduce A A [fn acc x [Add-add add-dict acc x]] [AdditiveIdentity-zero id-dict] xs

======================================== product — generic multiplicative fold over a list ======================================== product [Mul A] [MultiplicativeIdentity A] (List A) -> A Uses MultiplicativeIdentity dict as one, Mul-mul for accumulation.

spec product [Mul A] -> [MultiplicativeIdentity A] -> [List A] -> A
  :doc "Multiply a list using generic multiplication and a multiplicative identity as one"
defn product [mul-dict id-dict xs]
  reduce A A [fn acc x [Mul-mul mul-dict acc x]] [MultiplicativeIdentity-one id-dict] xs

======================================== int-range — generate a list of integers [start .. end-1] ======================================== int-range : Int -> Int -> List Int

spec int-range Int -> Int -> [List Int]
  :doc "Generate a list of integers from start (inclusive) to end (exclusive)"
defn int-range [start end]
  if [int-lt start end]
    cons Int start [int-range [int+ start 1] end]
    nil Int

======================================== First-Class Generic Arithmetic — RETIRED (N6f) ======================================== Since Numerics N6e-E2, the operator names themselves ARE first-class values: reduce + 0 xs and map negate xs work directly (in head position at arity 2, [+ a b] is the auto-widening keyword; everywhere else + denotes the lawful same-type Add function). Explicit-hole sections also work: [map [int* _ 2] xs], [+ 7 _] (N6e-E3). The old prefix wrappers (plus/minus/times/divide/negate-fn/ abs-fn) are retired — use the operator names directly.

======================================== Algebraic laws — standard property declarations ======================================== These are metadata-only in Phase 1: they register in the property store but do not generate code. Phase 2 (QuickCheck) will execute :holds clauses as randomized tests.

Semigroup / Monoid / Group

(property semigroup-laws ($brace-params A : (Type 0))
  (- :name "associativity"
     :forall ($brace-params x : A) ($brace-params y : A) ($brace-params z : A)
     :holds (eq? (add (add x y) z) (add x (add y z))))
  ($brace-params :where (Add A) (Eq A)))

(property monoid-laws ($brace-params A : (Type 0))
  (- :name "left-identity"
     :forall ($brace-params x : A)
     :holds (eq? (add additive-identity x) x))
  (- :name "right-identity"
     :forall ($brace-params x : A)
     :holds (eq? (add x additive-identity) x))
  ($brace-params :includes (semigroup-laws A) :where (Add A) (AdditiveIdentity A) (Eq A)))

Functor

(property functor-laws ($brace-params F : (-> (Type 0) (Type 0)))
  (- :name "identity"
     :forall ($brace-params xs : (F A))
     :holds (eq? (fmap id xs) xs))
  (- :name "composition"
     :forall ($brace-params f : (-> A B)) ($brace-params g : (-> B C)) ($brace-params xs : (F A))
     :holds (eq? (fmap (>> f g) xs) (fmap g (fmap f xs))))
  ($brace-params :where (Functor F)))

Commutativity

(property commutative-add-laws ($brace-params A : (Type 0))
  (- :name "commutativity"
     :forall ($brace-params x : A) ($brace-params y : A)
     :holds (eq? (add x y) (add y x)))
  ($brace-params :where (Add A) (Eq A)))
